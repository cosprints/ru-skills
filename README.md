# AI-скиллы Community Sprints

Рабочие скиллы (файлы `SKILL.md`) для Claude Code, Cursor и других AI-ассистентов, которыми пользуются участники сообщества AI Champions. Каждый скилл лежит в своей папке внутри `skills/`.

| Скилл | Что делает |
| --- | --- |
| [abcdx-segmentation](skills/abcdx-segmentation/SKILL.md) | Раскладывает платящих клиентов на сегменты A, B, C, D и X по марже и удовлетворённости, находит причинные критерии сегментов и собирает план перераспределения ресурсов. По методологии Ильи Красинского. |

## Как поставить

**Claude Code.** Скопируйте папку скилла в папку скиллов проекта или пользователя:

```bash
git clone https://github.com/cosprints/ru-skills.git
mkdir -p ~/.claude/skills
cp -R ru-skills/skills/abcdx-segmentation ~/.claude/skills/
```

После этого скилл доступен в любом проекте: попросите Claude «сделать ABCDX-сегментацию» и приложите выгрузку клиентов.

**Cursor и другие ассистенты.** Откройте `SKILL.md`, скопируйте его содержимое в системную инструкцию или в начало диалога, затем приложите данные.

**ChatGPT.** Вставьте содержимое `SKILL.md` первым сообщением, затем отправьте данные.

## Как добавить свой скилл

1. Создайте папку `skills/<название-скилла>/` с файлом `SKILL.md`.
2. В начале файла заполните поля `name` и `description`: по описанию ассистент понимает, когда применять скилл.
3. Опишите, что нужно на входе, процедуру по шагам и формат результата.
4. Откройте pull request или напишите команде: https://t.me/communitysprintsteam
